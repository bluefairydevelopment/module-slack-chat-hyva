# BlueFairy Slack Live Chat — Hyva

Hyva-compatible frontend widget built on Alpine.js and Tailwind CSS. Consumes the REST endpoints declared in the core module.

**Requires:** `bluefairy/module-slack-chat` + Hyva theme (`Hyva_Theme` module).

**Status:** Skeleton. Feature implementation follows milestone M11 in the approved plan.

**Plan:** `~/Sites/blueSites/plans/bluefairy-slack-live-chat-magento.plan.md`
